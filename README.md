# Portal Mod: Expanded

Portal Mod: Expanded adds blocks and testing elements that were missing in the base Portal Mod. Examples include Portal 1 styled
lunecast and blackplate,Portal 1 style buttons and doors, as well as new variants of overgrown blocks and testing elements.

As of Portal Mod: Expanded 1.2.0, or previously known as Expanded Arbor 1.2.0, Portal Mod Deco Blocks from the Portal Mod discord
has been merged into Portal Mod: Expanded.

# For Modders

The mod is built using JDK 17, but runs on Minecraft 1.16.5 on Java 8.\n

To compile the mod, download the source and run ./gradlew build
